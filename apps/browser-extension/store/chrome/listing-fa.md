# متن آماده Chrome Web Store

## نام پیشنهادی

RastChin راست‌چین - Persian RTL & Font

## خلاصه کوتاه

خواناتر کردن متن فارسی در ابزارهای وب با RTL فارسی‌محور، فونت Vazirmatn و حفظ خوانایی کد، لینک و متن انگلیسی.

## توضیح کامل

RastChin افزونه‌ای فارسی‌محور برای خواناتر کردن متن فارسی در مرورگر است. این افزونه نمایش متن‌های فارسی و متن‌های ترکیبی فارسی/انگلیسی را مرتب‌تر می‌کند تا جهت نوشتار، چینش متن و فونت‌ها طبیعی‌تر دیده شوند.

ویژگی‌ها:

- راست‌چین‌سازی هوشمند متن فارسی در ابزارهای وب پشتیبانی‌شده
- بهبود نمایش متن‌های ترکیبی فارسی و انگلیسی
- استفاده از فونت Vazirmatn برای خوانایی بهتر فارسی
- حفظ خوانایی کد، URL، ایمیل، مسیر فایل، Markdown و متن انگلیسی
- کنترل روشن/خاموش برای هر سایت پشتیبانی‌شده
- پردازش local داخل مرورگر، بدون ارسال متن صفحه به سرور

RastChin برای کاربرانی ساخته شده که در محیط‌های کاری، ابزارهای نوشتاری، چت، فرم‌ها و صفحات متنی با فارسی و انگلیسی سروکار دارند.

این افزونه روی مجموعه‌ای از سایت‌ها و ابزارهای وب پشتیبانی‌شده اجرا می‌شود. فهرست کامل سایت‌های پشتیبانی‌شده و سطح پشتیبانی هرکدام در وب‌سایت رسمی راست‌چین آمده است.

این افزونه وابسته، رسمی یا مورد تأیید هیچ سرویس یا وب‌سایت شخص ثالثی نیست.

## نکته حریم خصوصی برای listing

RastChin متن صفحه، promptها، پیام‌ها، سندها، کارت‌ها، کامنت‌ها و زیرنویس‌ها را به هیچ سروری ارسال نمی‌کند. ترجیح‌های نمایشی افزونه با `chrome.storage.sync` ذخیره می‌شود و پردازش جهت/فونت در همان مرورگر انجام می‌شود. مسیر بازخورد و پشتیبانی از طریق فرم وب‌سایت رسمی انجام می‌شود و فقط اطلاعاتی ارسال می‌شود که کاربر خودش وارد می‌کند.

## متن انگلیسی کوتاه برای dashboard

Persian-only RTL and Vazirmatn typography for supported web tools while keeping code, URLs and technical English readable.
