# سیاست حریم خصوصی RastChin

RastChin یک افزونه local-first است. هدف افزونه اصلاح نمایش متن فارسی و تایپوگرافی در سایت‌های پشتیبانی‌شده است.

## چه داده‌ای جمع‌آوری نمی‌شود

- متن صفحه، promptها، پیام‌ها، سندها، کارت‌ها و کامنت‌های کاربر جمع‌آوری یا ارسال نمی‌شود.
- افزونه telemetry، analytics یا ردیابی محتوای صفحه ندارد.
- افزونه داده‌ای را برای پردازش RTL یا فونت به سرور خارجی نمی‌فرستد.

## چه داده‌ای ذخیره می‌شود

- وضعیت روشن/خاموش بودن افزونه
- تنظیم روشن/خاموش هر پلتفرم
- تنظیمات نمایشی زیرنویس YouTube، شامل اندازهٔ فونت و رنگ انتخاب‌شده

این تنظیمات در `chrome.storage.sync` ذخیره می‌شوند تا رفتار افزونه بین نشست‌های مرورگر حفظ شود و ممکن است از طریق قابلیت همگام‌سازی مرورگر Chrome بین دستگاه‌های خود کاربر همگام شوند. پنل کناری این ترجیح‌ها را مستقیم از همین storage می‌خواند و تغییر می‌دهد. این داده‌ها فقط ترجیح‌های نمایشی هستند و شامل متن صفحه، زیرنویس، پیام، prompt یا محتوای خصوصی کاربر نمی‌شوند.

## دسترسی‌ها

RastChin فقط روی دامنه‌های اعلام‌شده در manifest اجرا می‌شود و برای اعمال RTL و
فونت به content script نیاز دارد. این دامنه‌ها شامل پلتفرم‌های پشتیبانی‌شده و
صفحه‌های عمومی Notion با دامنهٔ `notion.site` هستند. پردازش متن به‌صورت محلی در
مرورگر انجام می‌شود.

- `storage` فقط ترجیح‌های نمایشی بالا را نگه می‌دارد.
- `activeTab` پس از اقدام کاربر دسترسی موقت به تب فعلی می‌دهد.
- `sidePanel` رابط پنل کناری را فراهم می‌کند.
- `tabs` به پنل کناری اجازه می‌دهد ID و URL تب فعال را بخواند و هنگام تغییر تب یا
  navigation، پلتفرم فعال را دوباره تشخیص دهد؛ به‌ویژه وقتی content script پاسخگو
  نیست. افزونه history را enumerate یا ذخیره نمی‌کند و URL تب را ارسال نمی‌کند.

## Chrome Web Store Limited Use

RastChin's use and transfer of information received from Chrome APIs adheres to the
Chrome Web Store User Data Policy, including the Limited Use requirements.

## گزارش مشکل

اگر کاربر روی گزینه گزارش مشکل یا بازخورد کلیک کند، فرم پشتیبانی وب‌سایت رسمی
`rastchin.tools` در تب جدید باز می‌شود. هیچ متن صفحه‌ای به‌صورت خودکار به گزارش
اضافه نمی‌شود و کاربر فقط اطلاعاتی را که خودش در فرم وارد می‌کند ارسال می‌کند.

## تماس

برای سؤال یا درخواست حذف اطلاعات احتمالی مرتبط با پشتیبانی، با `hi@rastchin.tools` تماس بگیرید.
