# بریف طراحی تصاویر Chrome Web Store برای RastChin

مسیرهای نسبی این سند از `apps/browser-extension/` محاسبه می‌شوند.

این بریف برای طراحی دارایی‌های تصویری صفحه Chrome Web Store اکستنشن `RastChin راست‌چین - Persian RTL & Font` آماده شده است. هدف این است که کاربر فارسی‌زبان با دیدن تصاویر، در چند ثانیه بفهمد راست‌چین چه مشکلی را حل می‌کند، روی چه ابزارهایی کار می‌کند، و چرا می‌تواند به آن اعتماد کند.

## خلاصه اجرایی

برای انتشار حرفه‌ای، ۷ فایل تصویری جدید تولید شود. حداقل رسمی Chrome Web Store شامل آیکون، یک small promo tile و حداقل یک screenshot است، اما برای این انتشار باید مجموعه کامل زیر آماده شود:

1. `promo-small-440x280.png` - تصویر تبلیغاتی کوچک، الزامی
2. `promo-marquee-1400x560.png` - بنر Marquee، اختیاری ولی توصیه‌شده
3. `screenshot-1-ai-before-after-1280x800.png`
4. `screenshot-2-mixed-content-safe-1280x800.png`
5. `screenshot-3-work-tools-1280x800.png`
6. `screenshot-4-youtube-gmail-1280x800.png`
7. `screenshot-5-controls-privacy-1280x800.png`

آیکون ۱۲۸ در پروژه موجود است، اما گرافیست باید آن را از نظر کیفیت، خوانایی در سایز کوچک، هماهنگی رنگی و فضای خالی بررسی کند. اگر نیاز به اصلاح برند باشد، فایل آیکون هم جداگانه تحویل شود.

## مشخصات رسمی و فنی

- Store icon: فایل PNG با اندازه `128x128px`. اگر آیکون مربع است، خود طرح بهتر است حدود `96x96px` باشد و اطرافش فضای شفاف داشته باشد.
- Small promo tile: فایل PNG یا JPEG با اندازه دقیق `440x280px`. این تصویر الزامی است.
- Marquee promo tile: فایل PNG یا JPEG با اندازه دقیق `1400x560px`. اختیاری است، اما برای احتمال نمایش برجسته‌تر و آمادگی کامل انتشار توصیه می‌شود.
- Screenshots: حداقل ۱ و حداکثر ۵ تصویر. برای این پروژه باید هر ۵ تصویر تولید شود. اندازه پیشنهادی `1280x800px` است. گوگل `640x400px` را هم قبول می‌کند، اما `1280x800px` برای نمایشگرهای باکیفیت‌تر بهتر است.
- اسکرین‌شات‌ها باید full-bleed باشند: گوشه مربع، بدون padding شفاف، بدون حاشیه خالی دور تصویر، و بدون خروجی blur/pixelated.
- promo tileها locale-specific نیستند. چون RastChin محصول فارسی‌محور است، نسخه اصلی می‌تواند فارسی باشد، اما متن promoها باید بسیار کم و از نظر بصری قابل فهم باشد.
- promo tileها باید کل canvas را پر کنند، edge واضح داشته باشند و روی پس‌زمینه خاکستری روشن Chrome Web Store گم نشوند.
- خروجی نهایی باید sRGB و دقیقاً در اندازه اعلام‌شده باشد. بعد از export، ابعاد با ابزار سیستم یا Figma inspect بررسی شود.
- فرمت پیشنهادی همه خروجی‌ها PNG است، مگر اینکه تصویر واقعاً عکس‌محور شود و JPEG کیفیت/حجم بهتری بدهد.

## پیام محصول

راست‌چین یک افزونه فارسی‌محور است برای:

- راست‌چین کردن و خواناتر کردن متن فارسی در ابزارهای AI
- بهتر کردن تایپوگرافی فارسی با فونت Vazirmatn
- حفظ خوانایی متن‌های ترکیبی فارسی/انگلیسی
- حفظ خوانایی کد، URL، ایمیل، مسیر فایل، Markdown، جدول و متن انگلیسی
- کنترل جداگانه برای هر پلتفرم
- پردازش local-first داخل مرورگر، بدون ارسال متن صفحه به سرور

جمله ذهنی اصلی که تصاویر باید منتقل کنند:

«وقتی در ابزارهای انگلیسی فارسی می‌نویسم، راست‌چین متن فارسی را درست، خوانا و قابل‌اعتماد نمایش می‌دهد، بدون اینکه بخش‌های انگلیسی و فنی را خراب کند.»

## جدول حقیقت قابلیت‌ها

برای جلوگیری از اغراق در تصاویر، رفتار پلتفرم‌ها دقیقاً این‌طور نمایش داده شود:

- ابزارهای AI مثل ChatGPT، Claude، Gemini، Copilot، Perplexity، DeepSeek، NotebookLM، AI Studio، Qwen و Arena: RTL فارسی‌محور، فونت فارسی خواناتر، حفظ خوانایی متن ترکیبی.
- Trello: اصلاح scoped برای توضیحات و کامنت‌های کارت بازشده.
- Notion و `notion.site`: font-only برای خواناتر شدن فارسی؛ ادعای اصلاح کامل RTL نشود.
- Gmail: font-only برای خواناتر شدن فارسی؛ ادعای اصلاح کامل RTL نشود.
- YouTube: خواناتر کردن زیرنویس فارسی و کنترل اندازه/رنگ.
- همه موارد: پردازش داخل مرورگر؛ متن صفحه، prompt، پیام، سند، کارت یا کامنت به سرور ارسال نمی‌شود.

## مخاطب تصویرها

- فارسی‌زبان‌هایی که روزانه با ChatGPT، Claude، Gemini، Perplexity، Copilot و ابزارهای مشابه کار می‌کنند.
- توسعه‌دهنده‌ها و کاربران فنی که متن فارسی، کد، لینک، ایمیل و Markdown را در یک پیام ترکیب می‌کنند.
- تیم‌های کاری فارسی‌زبان که از Trello، Notion، Gmail و YouTube استفاده می‌کنند.
- کاربرانی که نگران دسترسی افزونه به متن صفحه و حریم خصوصی هستند.

## لحن بصری

تصاویر نباید شبیه خروجی AI، بنر آماده، mockup خیالی یا تبلیغ اغراق‌آمیز باشند. حس مطلوب:

- واقعی، محصول‌محور و قابل‌اعتماد
- تمیز، مدرن و کم‌حرف
- فارسی‌محور و RTL
- نزدیک به تجربه واقعی کاربر در مرورگر
- بدون تزئینات پلاستیکی، glowهای سنگین، گرادیان‌های مصنوعی، 3D بی‌ربط یا browser mockupهای غیرواقعی

قانون تولید تصویر: اولویت با screenshot واقعی از نسخه فعلی اکستنشن در Chrome است؛ Zoom برابر `100%`، theme روشن، داده demo و بدون اطلاعات واقعی. Figma فقط برای crop، چیدمان، callout محدود و هماهنگی برند استفاده شود. UI خیالی، پنجره مرورگر ساختگی، browser chrome غیرواقعی و تصویرسازی AI برای خود محصول ممنوع است.

## برند و تایپوگرافی

- نام انگلیسی محصول: `RastChin`
- نام فارسی محصول: `راست‌چین`
- نام کامل فروشگاهی: `RastChin راست‌چین - Persian RTL & Font`
- فونت فارسی پیشنهادی: Vazirmatn
- فونت لاتین پیشنهادی: Inter، system-ui یا فونت هماهنگ با UI Chrome
- جهت متن‌های فارسی: RTL
- جهت کد، URL، ایمیل و command: LTR
- متن داخل تصویرها باید کم، درشت و قابل‌خواندن باشد. گوگل توصیه می‌کند تصاویر حتی در نصف اندازه هم خوب کار کنند، پس متن‌های ریز و توضیح زیاد ممنوع است.
- هر screenshot فقط یک پیام اصلی و حداکثر یک callout کوتاه داشته باشد. هر promo بهتر است حداکثر ۶ تا ۸ کلمه visible copy داشته باشد.

رنگ‌ها باید با آیکون RastChin هماهنگ باشند، اما تصویرها نباید فقط یک صفحه زرشکی/صورتی یک‌دست باشند. پیشنهاد:

- زرشکی برند برای تاکید و CTA بصری
- پس‌زمینه‌های روشن و خنثی برای screenshotها
- خاکستری/مشکی نرم برای متن
- یک accent محدود برای highlight، نه برای شلوغ کردن تصویر

## محدودیت‌های محتوایی

- از badgeها و ادعاهای گمراه‌کننده مثل `#1`، `Editor's Choice`، `Best`، `Featured` یا «بهترین افزونه» استفاده نشود.
- پلتفرم‌های پشتیبانی‌نشده نمایش داده نشوند. فقط از این پلتفرم‌ها استفاده شود: ChatGPT، Claude، Gemini، Copilot، Perplexity، DeepSeek، NotebookLM، Google AI Studio، Qwen، Arena، Trello، Notion، Gmail و YouTube.
- اگر برندهای گوگل یا پلتفرم‌های دیگر در تصویر دیده می‌شوند، فقط در قالب screenshot واقعی محصول باشند؛ از لوگوها برای القای همکاری رسمی یا endorsement استفاده نشود.
- هیچ prompt، ایمیل، نام شخص، URL داخلی یا اطلاعات واقعی شرکت در تصویرها نیاید. از داده نمونه مثل `example.com` و `support@example.com` استفاده شود.
- در تصاویر مربوط به YouTube از چهره واقعی، محتوای کپی‌رایتی یا thumbnail قابل‌شناسایی استفاده نشود. یک فریم ویدئویی خنثی یا محتوای demo بی‌مساله کافی است.
- استفاده از AI-generated UI، لوگوی بازطراحی‌شده پلتفرم‌ها، blur/glow نمایشی، سایه‌های غیرواقعی، کارت‌های بیش از حد تمیز، متن placeholder و screenshot بدون spacing/scrollbar طبیعی ممنوع است.

## چک‌لیست کیفیت قبل از تحویل

- همه فایل‌ها اندازه دقیق دارند.
- نام frameهای Figma دقیقاً با نام فایل export یکی است.
- متن‌ها در نصف اندازه هم خوانا هستند.
- خروجی‌ها حس screenshot واقعی و محصول واقعی دارند، نه تصویر AI.
- screenshot خام هر تصویر در فایل Figma کنار نسخه نهایی نگه داشته شده است.
- هر screenshot با UI واقعی نسخه فعلی اکستنشن مقایسه شده است.
- هیچ اطلاعات واقعی شرکت یا کاربر در تصویرها نیست.
- هیچ پلتفرم پشتیبانی‌نشده‌ای نمایش داده نشده است.
- ادعای نادرست یا badge گمراه‌کننده وجود ندارد.
- فارسی RTL و طبیعی است.
- code، URL، ایمیل و commandها LTR و خوانا هستند.
- تصاویر از نظر برند با آیکون RastChin هماهنگ‌اند.
- promoها کم‌متن و حرفه‌ای هستند.
- اسکرین‌شات‌ها full-bleed و بدون padding شفاف هستند.
- خروجی‌ها در preview حدود `50%` بررسی شده‌اند.
- قبل از upload نهایی، preview داخل Chrome Web Store Developer Dashboard هم چک شود.
