# متن آماده Firefox Add-ons

## نام

RastChin راست‌چین - Persian RTL & Font

## خلاصه

خواناتر کردن متن فارسی در ابزارهای وب با RTL فارسی‌محور، فونت Vazirmatn و حفظ خوانایی کد، لینک و متن انگلیسی.

## توضیح کامل

RastChin افزونه‌ای فارسی‌محور برای خواناتر کردن متن فارسی و متن‌های ترکیبی فارسی/انگلیسی در Firefox است.

ویژگی‌ها:

- راست‌چین‌سازی هوشمند متن فارسی در ابزارهای وب پشتیبانی‌شده؛
- استفاده از فونت محلی Vazirmatn؛
- حفظ جهت و فونت مناسب کد، URL، ایمیل، مسیر فایل، Markdown و متن انگلیسی؛
- کنترل روشن/خاموش سراسری و جداگانه برای هر میزبان؛
- پنل کناری Firefox برای وضعیت، تنظیمات و تاریخچهٔ تغییرات؛
- پردازش کاملاً محلی، بدون تله‌متری یا ارسال محتوای صفحه.

فایل `manifest.json` بسته و README افزونه در مخزن عمومی، مرجع میزبان‌های پشتیبانی‌شده و مجوزهای نسخهٔ جاری هستند. RastChin مستقل است و هیچ وابستگی یا تأیید رسمی از سوی سرویس‌های شخص ثالث ندارد.
