# سیاست حریم خصوصی افزونهٔ Firefox راست‌چین

راست‌چین یک افزونهٔ local-first و فارسی‌محور است. پردازش جهت متن، فونت و تشخیص محتوای ترکیبی در همان مرورگر انجام می‌شود.

## داده‌ای که جمع‌آوری یا ارسال نمی‌شود

- متن صفحه، prompt، پیام، سند، کارت، کامنت و زیرنویس؛
- تاریخچهٔ مرور، URL تب‌ها یا محتوای فرم‌ها؛
- اطلاعات شناسایی، مالی، سلامت یا موقعیت مکانی؛
- تله‌متری، تحلیل استفاده یا شناسهٔ تبلیغاتی.

manifest نسخهٔ Firefox در `browser_specific_settings.gecko.data_collection_permissions` مقدار `none` را اعلام می‌کند.

## دادهٔ محلی

وضعیت روشن/خاموش افزونه، تنظیم هر میزبان و ترجیح‌های نمایشی زیرنویس YouTube در `storage.sync` مرورگر نگه‌داری می‌شوند. Firefox ممکن است این ترجیح‌ها را از طریق قابلیت همگام‌سازی حساب خود کاربر میان دستگاه‌های او منتقل کند. این داده‌ها شامل محتوای صفحه یا گفتگو نیستند.

## دسترسی‌ها

- `storage` فقط ترجیح‌های نمایشی را نگه می‌دارد.
- `activeTab` پس از اقدام کاربر دسترسی موقت به تب فعلی می‌دهد.
- `tabs` به پنل کناری اجازه می‌دهد ID و URL تب فعال را فقط برای تشخیص میزبان پشتیبانی‌شده بخواند. URL ذخیره یا ارسال نمی‌شود.
- `sidebar_action` رابط پنل کناری Firefox را به فایل محلی افزونه متصل می‌کند.

content scriptها فقط روی دامنه‌های صریح manifest اجرا می‌شوند. افزونه هیچ درخواست شبکه‌ای برای پردازش RTL یا فونت ایجاد نمی‌کند.

## پشتیبانی

دکمه‌های بازخورد و گزارش مشکل، قالب عمومی ایشوی GitHub را باز می‌کنند و هیچ محتوایی را خودکار به گزارش اضافه نمی‌کنند. اطلاعات خصوصی یا اعتبارنامه را در ایشوی عمومی قرار ندهید.

برای سؤال حقوقی یا حریم خصوصی با `hi@rastchin.tools` تماس بگیرید.
