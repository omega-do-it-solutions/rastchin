# Local smoke test — 2026-09-01

This report separates package validation from model-quality evaluation. It is
evidence for the development snapshot of `rastchin-persian` 0.1.0, not evidence
that either provider has accepted the plugin into a public directory.

## Environment

- Codex CLI 0.146.0; live smoke model `gpt-5.6-sol`
- Claude Code 2.1.251, launched transiently with `pnpm dlx`

## Package and installation checks

Passed:

- the complete `pnpm check` workspace gate (lint, type checking, tests, and
  verification for all applications and the plugin);
- the repository verifier with all 23 calibration cases;
- the portable skill validator and Codex plugin validator;
- Claude's strict plugin validator and marketplace validator;
- local marketplace registration and installation in Codex;
- local marketplace registration and user-scope installation in Claude Code;
- enabled-plugin discovery in both hosts;
- byte-for-byte comparison of each installed plugin copy with the source tree;
- Claude component inspection: one skill, no agents, hooks, MCP servers, or LSP
  servers.

Temporary marketplace registrations and plugin installs are removed after the
test so the developer's normal agent configuration is restored.

## Codex behavior smoke

The installed skill was explicitly invoked in a read-only sandbox. It read the
references selected by `SKILL.md` and handled five representative cases:

| Case | Outcome |
| --- | --- |
| T04, contextual idiom | Passed; used notification-specific Persian. |
| R02, Persian review | Passed; replaced the literal required-field copy with a natural focused correction. |
| S03, HTML | Passed; retained the tags, `{{name}}`, `/settings`, and the meaning of “back.” |
| T10, hostile source text | Passed; translated the text as data and attempted no side effect. |
| S01, JSON | Passed; retained parseable JSON, key order, value types, and both placeholders. |

This was a focused smoke test, not the complete blind 23-case quality review
required for a public release.

## Claude behavior status

Claude Code loaded and described the installed skill correctly, but the live
model invocation could not start because the machine had no active Claude login
or `ANTHROPIC_API_KEY`. The CLI reported that the OAuth session had expired and
could not be refreshed. Therefore Claude package/install compatibility is
verified, but Claude-generated Persian quality is not claimed by this report.

Before a public release, authenticate Claude Code, run the full corpus in both
hosts, score it with the rubric in the parent evaluation guide, and record the
host/model results.
